# POS System (Full Stack Web Application)

## Overview

This project is a **full-stack Point of Sale (POS) system** designed to manage sales transactions, inventory, and financial records for a retail business.
The system allows administrators and cashiers to handle daily sales, track product inventory, and generate financial reports.

The application is built using modern web technologies including **React for the frontend**, **Node.js and Express for the backend**, and **MySQL as the relational database**.

---

## Features

### Product Management

* Add, update, and delete products
* Manage product categories
* Track product cost price and selling price
* Monitor stock quantity

### Sales Management

* POS interface for quick sales
* Add products to cart
* Automatic calculation of totals
* Discount and tax handling
* Payment method support (cash, card)

### Inventory Management

* Automatic stock reduction after each sale
* Low stock monitoring
* Supplier tracking

### Financial Records

* Daily sales tracking
* Expense recording
* Profit calculation
* Sales reports

### User Management

* Admin and cashier roles
* Secure authentication
* Access control
